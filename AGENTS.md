# Codex instructions for Scene Tracker

Read `CODEX_IMPLEMENTATION_PLAN.md` before editing code. Implement one phase at a time, in order. After each phase run its listed tests, update `docs/implementation-status.md`, and stop for review. Do not claim mock tests validate pretrained model quality. Never download model weights as part of unit/CI tests. Do not implement camera calibration/registration, a frontend, OpenUSD, or fused 3D. Input is four fixed-role images (`cam_01..cam_04`, fourth overhead); keep originals immutable. Use Python and uv; keep GPU code out of API imports. Preserve ambiguous cross-view associations for human review. PointDiT is a separate Python 3.12 worker and produces per-view PLY, not a fused point cloud. If model access is blocked, record the blocker and keep fake contracts tested; do not substitute fake inference in real mode.
