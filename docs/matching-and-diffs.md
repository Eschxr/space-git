# Matching and diffs

Implementation is deferred to Phases 5–8. First establish temporal identities
within each fixed camera; propose conservative cross-camera candidates for review.
Unknown overlap, identical objects and overhead appearance changes must preserve
uncertainty. Missing observations do not prove removal. Displacements are pixel
or normalized image coordinates, never metres. Accepted changes form linear,
immutable revisions with evidence; no branching or merging is planned.
