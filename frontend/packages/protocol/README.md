# SpaceGit protocol v1

Python request models in the edge service validate v1; TypeScript response types are in types.ts. The scene JSON contract is scene.v1.schema.json, generated by scripts/export-schema.py. The versioned gallery fixture is also an example scene document. Wire position is [x right, y up] from the lower-left measured anchor center; Z points out of the wall. Dimensions are meters, angle is radians counterclockwise. Camera and projector pixels have origin at top left. Projector overlay points are normalized by the calibrated framebuffer dimensions. A live envelope carries a server session sequence, Unix seconds, processing milliseconds, device identity and fixture/live provenance. Scene commits and physical evidence have separate lifecycles.
